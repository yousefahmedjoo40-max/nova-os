# NeonOS 1.0

نظام مبني على Debian 12 (XFCE) بواجهة نيون وشريط مهام على طريقة ويندوز.

- **Settings**: شبكة/Wi-Fi، مظهر وشريط المهام (4 جهات)، لغة، درايفرات (NVIDIA تلقائي)، تحديثات (نقطة صفراء)، ألعاب (22)، تطبيقات ويندوز (.exe)، وضع خفيف.
- **Task Manager**: عمليات + مخططات أداء حيّة (Ctrl+Shift+Esc).
- **الموقع**: `site/index.html` بـ 12 لغة، ينشره workflow `pages.yml` على GitHub Pages.
- **التحديثات**: `publish-update.yml` — راجع `docs/AUTO_PUBLISH.md`.

البناء: `docs/BUILD.md`. الاختبار على VirtualBox: `docs/VIRTUALBOX_TEST.md`.
