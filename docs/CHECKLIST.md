# قائمة اختبار NovaOS

## الإقلاع والتثبيت
- [ ] الإقلاع عبر BIOS (Legacy) ناجح.
- [ ] الإقلاع عبر UEFI ناجح.
- [ ] خيار "Live" يعمل بدون تثبيت.
- [ ] Calamares يبدأ ويكمل التثبيت على قرص فعلي/افتراضي بدون أخطاء.
- [ ] بعد التثبيت وإعادة الإقلاع، النظام يقلع من القرص مباشرة.

## سطح المكتب
- [ ] XFCE يقلع بدون أخطاء رسومية.
- [ ] جميع اختصارات التطبيقات (ThermalCtl, AI Assistant, Updater, Minecraft)
      تظهر في قائمة التطبيقات.

## الشبكة
- [ ] الإنترنت يعمل عبر Ethernet من أول إقلاع.
- [ ] nm-applet يعرض شبكات WiFi المتاحة (على جهاز حقيقي بكرت WiFi مدعوم).
- [ ] الاتصال بشبكة WiFi محمية بكلمة مرور ينجح ويحفظ الإعداد بعد إعادة الإقلاع.
- [ ] USB Tethering من هاتف يُكتشف كواجهة شبكة تلقائياً.

## ThermalCtl
- [ ] الواجهة تفتح وتعرض استهلاك CPU/RAM بشكل حي.
- [ ] على جهاز حقيقي: الحرارة تُعرض بشكل صحيح من lm-sensors.
- [ ] داخل VM: تظهر رسالة واضحة "لا توجد حساسات" بدون تعطّل التطبيق.
- [ ] تبديل الوضع (Silent/Balanced/Performance) يُحدّث `scaling_governor`
      فعلياً على جهاز حقيقي (تحقق بـ `cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor`).
- [ ] تفعيل MangoHud يُنشئ `~/.config/MangoHud/MangoHud.conf` بنجاح.
- [ ] ضبط FPS cap يُحدّث نفس الملف بقيمة `fps_limit`.

## AI Assistant
- [ ] بدون مفتاح API: رسالة خطأ واضحة "لا يوجد مفتاح API محفوظ".
- [ ] بعد إدخال مفتاح صحيح من الإعدادات: يحفظ في `/etc/novaos/ai.key`
      بصلاحيات `600` ومالك `root` (تحقق بـ `ls -l /etc/novaos/ai.key`).
- [ ] قطع الإنترنت يُظهر رسالة "تعذّر الاتصال بالإنترنت" بدون كراش.
- [ ] مفتاح خاطئ يُظهر رسالة "مفتاح API غير صحيح".
- [ ] عند اقتراح المساعد لأوامر، يظهر مربع تأكيد قبل أي تنفيذ، ولا يُنفَّذ
      شيء تلقائياً بدون موافقة صريحة.
- [ ] تغيير اسم الموديل من الإعدادات يُحدّث `/etc/novaos/config.json` فعلياً.

## نظام التحديثات
- [ ] تنفيذ `python3 updater.py check` يتصل بـ Supabase بنجاح (مع URL/anon
      key حقيقيين) ويعرض آخر نسخة متاحة.
- [ ] فرق SHA256 متعمّد يُلغي التحديث برسالة خطأ واضحة ولا يثبّت الحزمة.
- [ ] توقيع minisign صحيح يمر التحقق؛ توقيع غير صحيح يُظهر تحذيراً.
- [ ] `python3 updater.py rollback` يعيد النسخة السابقة من الكاش المحلي بنجاح.
- [ ] RLS على Supabase: استدعاء REST API بـ anon key يسمح بالقراءة فقط
      (أي محاولة INSERT/UPDATE/DELETE بنفس المفتاح يجب أن تُرفض).

## Minecraft
- [ ] أول تشغيل يثبّت Prism Launcher تلقائياً عبر Flatpak إن لم يكن مثبتاً.
- [ ] ملف `novaos-jvm-args.txt` يحتوي قيمة ذاكرة منطقية بناءً على رام الجهاز.
- [ ] GameMode يُفعَّل تلقائياً إن كان متوفراً.
- [ ] التشغيلات اللاحقة لا تعيد التثبيت (ملف marker يعمل بشكل صحيح).

## ملاحظات خاصة بالأجهزة الافتراضية (VirtualBox/VMware/QEMU)
- لا توجد حساسات حرارة حقيقية → سلوك متوقع، ليس خللاً.
- لا يوجد دعم turbo/boost حقيقي → ThermalCtl يسجّل ملاحظة في اللوج فقط.
- درايفر nvidia الحقيقي لن يُحمَّل لأن الـ GPU وهمي.
- MangoHud يعمل لكن أرقام الأداء غير واقعية بدون تمرير GPU حقيقي.
- WiFi عبر nm-applet لا يمكن اختباره بشكل كامل إلا بتمرير USB حقيقي أو
  على جهاز فعلي.
